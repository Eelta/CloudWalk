# CloudWalk

## 简介

CloudWalk提供随声听功能，在Skyrim中实时收听网易云音乐。

## 功能

- 极简随声听，显示歌名、歌手，提供播放开关、上一首、下一首和应用音量。
- 支持导入网易云歌单/专辑链接，自定义电台名；最多48个电台，每页8个。
- 按住快捷键V打开电台轮盘，移动鼠标到对应选区即可换台。左键上一页，右键下一页，循环翻页。

## 安装

需开启网易云应用，在设置-系统-开启SMTC，游戏时保持网易云开启。

在SKSE菜单，设置各类选项和快捷键。

| 操作 | 默认键鼠输入 | 默认手柄输入 |
| --- | --- | --- |
| 开关随声听 | 6 | LB+A；调整模式中Y |
| 上一首 / 下一首 | 7 / 8 | LB+方向键左 / 右；调整模式中LB / RB |
| 打开电台轮盘 | 按住V | 先按住LB，再按住RB |
| 选择 / 确认电台 | 移动鼠标 / 松开V | 右摇杆 / 松开LB或RB |
| 上一页 / 下一页 | 轮盘中左键 / 右键 | 轮盘中LT / RT，也可用方向键左 / 右 |
| 缩放轮盘 | 轮盘中滚动鼠标滚轮 | 轮盘中方向键上 / 下 |
| 调整随声听/轮盘位置和大小 | Enter打开调整模式 | LB+X打开调整模式 |
| 选择并移动界面 | 调整模式中左键点击并拖动 | 调整模式中A选择、左摇杆移动 |
| 缩放已选界面 | 调整模式中滚动鼠标滚轮 | 调整模式中右摇杆上、下 |
| 调整应用音量 | 随声听音量滑块 | 调整模式中方向键左 / 右 |
| 取消/ 结束调整 | Esc；调整模式也可再次按 Enter | B |

## 声明

CloudWalk 为独立模组，与网易云无官方关联。账号、网络、地区、会员与版权限制由网易云处理。

模组不包含音乐文件，不读取 Cookie，不使用第三方网易云服务，不提供下载功能。

音乐由网易云播放，模组负责游戏内显示、操作和原版背景音乐接管。通过接口控制电台、发送播放／暂停、音量控制、切歌请求等官方客户端SMTC已开放功能。
